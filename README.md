# go.trevorrose.com

Dealer snapshot pages for Trevor Rose Consulting, served by GitHub Pages at https://go.trevorrose.com.

Each dealer gets a folder with an `index.html`, so pages live at `https://go.trevorrose.com/<dealer-slug>/`.
The root page redirects to trevorrose.com. `robots.txt` and each page's meta tags keep everything out of search engines.
